Sovol 3D SO-1

https://yuriichuf.github.io/plotter/

Полный набор веб-инструментов для работы с векторной графикой, создания шрифтов и подготовки G-кода для плоттера Sovol SO-1. Все инструменты работают полностью в браузере без необходимости установки дополнительного ПО.

🌟 Особенности

· Полностью в браузере - не требует установки, работает на любом устройстве
· Локальная обработка - все файлы обрабатываются на вашем компьютере
· Поддержка SVG - современный векторный формат
· Экспорт в G-код - готовые файлы для плоттера Sovol SO-1
· Темная тема - удобная для глаз цветовая схема

🛠 Инструменты в наборе

1. Векторный редактор (VectorImageTracer.html)

Простой, но мощный векторный редактор для создания и редактирования векторных изображений.

Основные возможности:

· Рисование линий, прямоугольников, кругов, кривых Безье
· Инструмент "Перо" для создания плавных кривых
· Загрузка изображений как подложки для трассировки
· Инструменты "Ластик" и "Выталкивание" для редактирования
· Настройка толщины линий и цвета
· Экспорт в SVG формат

2. Редактор SVG шрифтов (Redactorsvg.html)

Профессиональный редактор для создания и редактирования векторных шрифтов.

Основные возможности:

· Создание и редактирование глифов (символов шрифта)
· Загрузка системных шрифтов как подложки для трассировки
· Точные направляющие и сетки для выравнивания
· Инструменты зеркалирования и отражения
· Работа с контрольными точками Безье
· Сохранение и загрузка SVG шрифтов
· Инструмент наладки для сравнения с эталонными шрифтами

3. Редактор текста для плоттера (TextTOplot.html)

Инструмент для компоновки текста и векторных элементов перед печатью.

Основные возможности:

· Работа с текстом (создание, редактирование, позиционирование)
· Загрузка пользовательских SVG шрифтов
· Импорт SVG изображений
· Настройка размеров листа (A4, A3, пользовательские)
· Фоновая подложка для точного позиционирования
· Динамическое изменение свойств элементов
· Экспорт в SVG и G-код

4. Конвертер в G-код (gui_gkode.html)

Специализированный конвертер изображений в G-код для плоттера Sovol SO-1.

Основные возможности:

· Поддержка форматов: JPEG, PNG, SVG, BMP, GIF
· Продвинутые настройки трассировки изображений
· Оптимизация путей для минимального времени печати
· Предпросмотр векторных контуров
· Настройки скорости и параметров плоттера
· Автоматическая центровка и масштабирование
· Генерация G-кода с учетом особенностей Sovol SO-1

📋 Технологии

· HTML5 - структура и семантика
· CSS3 - стилизация и адаптивный дизайн
· JavaScript (ES6+) - логика и интерактивность
· SVG API - работа с векторной графикой
· Canvas API - обработка растровых изображений
· File API - работа с файлами в браузере


⚠️ Ограничения и предупреждения

· Проект предназначен для образовательных и личных целей
· Все операции выполняются локально в браузере
· Для работы некоторых функций требуется современный браузер
· Не рекомендуется использовать для коммерческих проектов без дополнительного тестирования
